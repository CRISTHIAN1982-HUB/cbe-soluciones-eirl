CBE SOLUCIONES E.I.R.L. — sitio web estático

Archivos:
- index.html: página principal
- styles.css: diseño responsive
- script.js: menú y filtros interactivos
- robots.txt y sitemap.xml: preparación SEO

Publicación recomendada:
1. Comprar un dominio, por ejemplo cbesoluciones.com.pe (comprobar disponibilidad antes de comprar).
2. Contratar hosting con SSL.
3. Subir estos archivos a public_html.
4. Activar HTTPS y redirección HTTP -> HTTPS.
5. Registrar el dominio en Google Search Console como propiedad de dominio y verificar DNS.
6. Enviar https://TU-DOMINIO/sitemap.xml.

Nota: las fotos de demostración usan imágenes remotas de Unsplash. Para una versión final, conviene sustituirlas por fotos propias de CBE o imágenes con licencia que controles.
